## Summary
This PR successfully implements pinned library components with exact version metadata, typed instance props, variant tracking, and platform-specific exports. The code is well-tested, safely separates untrusted data (manifests) from execution, and leverages the underlying semantic node system effectively to provide graceful fallback and portable clipboards.

## Strengths
- **Secure architecture:** Manifest imports are strictly validated and canonicalized without evaluation, preventing XSS/execution while retaining rich semantic behavior.
- **Robust testing:** The exhaustive validation suite, real e2e consumer testing for web/SwiftUI, and tests handling schema collisions and explicit remapping verify the implementation.
- **Atomic state management:** Library metadata failures (like `library.remap` with invalid variants/properties) atomically fail before modifying the `SceneDocument`.

## Findings

### [WARN]
- **`src/web/src/app/model/clipboard.ts`, line 42**: Copied library children fail to paste entirely if their parent isn't also copied. Because `validateLibraryBindings` strictly rejects a `librarySlot` without a `libraryRef` parent, copying a slotted child alone (where `parentId` becomes `null` during paste) causes `validateDocument` to reject the entire paste batch. Fix by clearing `librarySlot` when a node's parent is stripped: `librarySlot: allIds.has(n.parentId ?? '') ? n.librarySlot : ''`.

### [NIT]
- **`src/web/src/app/model/library-schema.ts`, line 407**: The `if (node.librarySlot)` check skips validation for the default `""` slot because it is falsy. This allows nodes to be assigned as default slotted content even if the parent library component explicitly omits `""` from its `slots` definition. Consider explicitly checking `if (node.librarySlot !== undefined)` or validating all children of a `libraryRef` parent.
