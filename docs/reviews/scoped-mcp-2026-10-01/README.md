# Scoped MCP acceptance — October 1, 2026

Issue #50 adds compact editor discovery, document/page/subtree/selection reads with stable targeting and pagination, and bounded native WebView crops. The existing editor/store remains authoritative. Input/output schemas are versioned and accepted by the actual pinned MCP SDK over HTTP and stdio. Component reference metadata points to definitions that can be fetched with another subtree read; this is not a second writable scene.

The owned Debug app uses bundle ID `io.zubair.SugarMaple.ScopedQA`, `build/scoped-qa/profile` and port 48489. No working documents or production profile were touched. `tools/native-scoped-test.ts` refuses other profiles/ports. Its setup creates the small fixture; native keyboard editing changes X to 12, and `--verify-human` compares scoped/authoritative values, rejects the old revision and undoes the edit. The default phase checks HTTP/stdio equality, unknown/wrong targets, invalid crops/scales, read/capture checkpoint immutability and exact PNG dimensions. The screenshot shows the real bundled WKWebView. The cropped screenshot uses (400,200,240,160); its RGB mean absolute error against that area of the full capture is below 2 per channel, accounting for WebKit edge antialiasing/downsampling. Pixel dimensions are exact; byte equality is not claimed.

`--scale`, after setup/human verification, replaces only the owned fixture with 1,000 then 10,000 nodes in 500-operation batches. It compares the complete first subtree with authoritative nodes and traverses every page without duplicate/missing IDs. A 100-node response stays near 93 KB; full responses grow from 0.93 MB to 9.32 MB. At 10,000 nodes, the full read took about 1,021 ms, first scoped read 205 ms, and the worst of ten warm scoped reads 9.85 ms on this Mac. See the raw metrics; these are local observations, not a release performance distribution. Groups are hidden to isolate the read path from visible Canvas/Layers rendering.
