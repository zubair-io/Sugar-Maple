# Repeat Grid gesture handoff and WK fixture isolation

A command can commit immediately before a designer begins a new Repeat Grid drag. Queued revision effects previously cleared that fresh gesture as though it belonged to the old revision. The regression fails in production WKWebView on current-main integration4c1f18b with an isolated synthetic pen ID700001: the command is committed, the new drag starts without a render opportunity, and both the draft and projected cells disappear. `isolated-handoff-before.log` and its source JSON retain that failure independently of the mouse collision.

Repeat previews now retain their document/page/revision epoch. Projection and surface cancellation discard stale gestures but preserve a current one; tool changes, selection changes, deletion, mode changes, Escape and pointer cancellation retain their existing cancellation guards. A preview never changes the authored document, journal or revision. Completion still emits one typed resize and exact undo restores local text/image data and surviving cell IDs.

The later WK diagnostic trace also caught trusted mouse movement using pointer ID1 while the fixture's synthetic pen used the same ID. That mouse could overwrite the pen preview, explaining a reproduced intermittent failure class. The fixture now uses a distinct ID700001 and deliberately sends a different mouse pointer during the pen drag; the captured pen's preview must survive. Pointer/cell/history assertions and timing tolerances are unchanged. A bounded event trace appears only in failure diagnostics. This fixture change uses the existing production pointer-ID guard, rather than suppressing mouse events or weakening cancellation.

The original uninstrumented failure is retained. Its precise cause cannot be reconstructed from that log; no retrospective cause is invented. The new command-handoff failure and pointer collision are observed independently and receive regression coverage.
