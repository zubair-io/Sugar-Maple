# Public snapshots and receipt integrity

Final implementation source `08cb891f13d22d6f35af4d9130b34b8a6b96f79f`, stacked on metadata candidate `ba4024b` (#101). Returned nested scene values, cached editor reads and transaction/retry receipts previously shared references with the authoritative scene or recovery history. Mutating a gradient stop could change the scene and base at revision 0 without undo; mutating a receipt could poison replay, and snapshot mutation after an edit could make saved history fail recovery.

The repair detaches complete public document projections, scoped/discovery/comment reads and returned receipts. Internal edits, checkpoint assembly and replay use a private projection before their existing validation/copy boundaries, avoiding unnecessary public snapshots. Reading the authoritative ID does not project the whole document. No command, receipt format, valid authored semantics or undo origin is changed.
